# README media

This directory contains the screenshots and walkthrough media used by the
repository README. Stable paths prevent documentation links from breaking when
an asset is replaced.

Current assets:

- `dictation-demo.mp4` — nine-second push-to-talk dictation walkthrough
- `dictation-demo-poster.png` — linked poster frame for the walkthrough
- `meeting-history.png` — native meeting history and search interface

Use PNG or WebP for screenshots, crop out unrelated personal information, and
include descriptive alt text in the root README. Keep committed videos short and
web-friendly; prefer a GitHub-hosted attachment URL when a walkthrough is too large
for ordinary Git history.
